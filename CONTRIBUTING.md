# Contributing to FTL

Thank you for your interest in contributing to FTL! This contribution guide, especially the AI contribution policy, is influenced by [Rust](https://github.com/rust-lang/rust/blob/main/CONTRIBUTING.md), [LLVM](https://llvm.org/docs/Contributing.html), and [Ghostty](https://github.com/ghostty-org/ghostty/blob/main/AI_POLICY.md).

## Ways to Contribute

### Reporting Issues

If you find a bug or something is not working as expected, please [open an issue](https://github.com/nuta/ftl/issues/new). It would be extremely appreciated if you could provide a [minimal reproducible example](https://stackoverflow.com/help/minimal-reproducible-example).

### Sending Pull Requests

Send PRs on [GitHub](https://github.com/nuta/ftl/pulls). Every PR should:

- be formatted with `cargo fmt`.
- include tests (optional for the time being).
- not contain unrelated changes (please open a separate PR!).
- be an isolated change - keep a PR small as possible, and focused on a single issue.

> [!NOTE]
>
> If you are interested in FTL and looking for a project to work on, post on [GitHub Discussions](https://github.com/nuta/ftl/discussions) or [contact me](https://seiya.me).

## AI Contribution Policy

We accept AI-assisted contributions, including on GitHub issues and discussions. We consider AI as a development tool that helps you be more productive.

Please make sure to:

- **AI usage must be disclosed:** In PR description or issue comment, disclose AI you used. This is optional, but it is recommended to help other humans.
- **Keep a human in the loop:** You should review and understand the code first, before showing it to other humans.
- **You are responsible for what you submit:** Submitting low-quality AI-generated code/text may lead to a block of your contributions. Don't worry, this is for low-effort spams.

> [!NOTE]
>
> This policy does not apply to maintainers who already have a high level of trust.
